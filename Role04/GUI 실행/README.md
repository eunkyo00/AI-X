# 팀원별 로컬 설치·실행 안내

이 폴더에서 **Context Search 실행.command**를 더블클릭하면 됩니다. Codex에게 요청할 필요가 없습니다.

각자의 컴퓨터에서 설치한 뒤 실행합니다. 다른 사람의 `127.0.0.1` 주소로는 접속할 수 없습니다. 실행하면 본인 컴퓨터의 브라우저가 열립니다. 실행 중인 터미널을 유지하고 종료할 때 **Ctrl+C**를 누르세요. 브라우저 탭만 닫으면 서버는 계속 실행됩니다.

## 저장소 받기

GitHub에서 이 안내가 포함된 브랜치를 내려받으세요. main에 반영되기 전에는 아래 명령을 사용합니다.

```sh
git clone --branch codex/gui-team-local-launch https://github.com/eunkyo00/AI-X.git
cd AI-X
```

이미 저장소가 있으면 작업을 저장한 뒤 `git fetch origin`, `git switch codex/gui-team-local-launch`, `git pull --ff-only`를 차례로 실행하세요. 전체 저장소가 필요하므로 이 폴더만 따로 받거나 shallow clone을 사용하지 마세요.

## 설치 및 실행

- macOS: `Context Search 실행.command`
- Windows: `Context Search 실행.cmd` (Windows 실제 실행은 미검증)
- 처음 사용하는 팀원: Python 3.13과 Git을 설치하고 전체 저장소를 받은 다음 `처음 설치.command` 또는 `처음 설치.cmd`를 한 번 실행합니다. 최초 패키지·모델 다운로드에는 인터넷이 필요합니다.

실행기가 이미 실행 중인 이 프로젝트의 서버를 찾으면 그 화면을 엽니다. 기본 포트 5173이 사용 중이면 5174~5193에서 빈 포트를 선택합니다. 최종 주소는 터미널에 표시됩니다. 이 폴더만 따로 복사하면 실행되지 않습니다.

## 화면 사용

1. **검색:** `SARIMA 예측 코드`, `2026년 4월 수정한 강의자료`, `지난달 수정한 파일` 등을 입력합니다. 상대 날짜는 실행하는 컴퓨터의 현재 날짜를 기준으로 합니다.
2. **검색 결과:** 파일을 선택하고 검색 근거·관련 파일 탭을 확인합니다. `확인된 참조`는 정적 파일 참조이고, 실제 실행·사용 이력을 뜻하지 않습니다. 유사한 내용이나 파일명 기반 관계는 `추정`으로 표시합니다.
3. **열기:** 코드·텍스트·이미지·PDF를 미리 보거나 원본을 다운로드합니다.
4. **파일 등록:** 파일 또는 폴더 선택 → 선택한 파일 등록 → `검색 준비 완료`까지 기다립니다. 원본은 바꾸지 않고 앱의 실행 폴더로 복사합니다. 등록 파일은 브라우저를 닫아도 남습니다.
5. **내 파일 → 데이터·검색 인덱스 갱신:** 앱 실행 데이터의 본문·DB·임베딩·관련 파일을 다시 만듭니다. GitHub의 코드를 다운로드하는 버튼은 아닙니다. 갱신 중에는 검색을 잠시 멈추고 진행 상태를 표시합니다.

등록 형식: PDF, CSV, TSV, XLSX, PPTX, DOCX, TXT, Python, R, MD, JSON, IPYNB, HTML, CSS, JS, SQL. 파일당 25MB입니다. 폴더 선택 시 파일별로 차례로 등록합니다. 새 이미지·OCR 전용 문서 등록은 지원하지 않습니다. 기존 OCR 본문은 원본 해시가 일치할 때 재사용합니다. 본문이 없는 파일은 검색 준비 완료로 표시하지 않습니다.

## 폴더 자동 연결과 설명 생성

내 파일의 **폴더 자동 연결**에 자료 폴더의 전체 경로를 입력하면 앱이 켜진 동안 추가·수정·삭제를 반영합니다. 원본은 읽기만 하고 각자 앱 데이터에 복사합니다. 연결 해제 후 보관본은 남습니다.

Qwen 새 설명 생성은 선택 기능입니다. 로컬 Ollama에 `qwen3.5:4b`가 설치되어 실행 중이면 사용하며, 없으면 기존 설명·본문 검색·자동 분류로 계속 동작합니다.

## 문제가 생겼을 때

- **패키지 없음:** `처음 설치` 파일을 다시 실행합니다. 기존 등록 데이터는 유지합니다.
- **모델 다운로드 실패:** 인터넷 연결을 확인하고 다시 실행합니다. 모델을 이미 받은 뒤에는 `HF_HUB_OFFLINE=1` 환경 변수로 오프라인 실행할 수 있습니다.
- **갱신 실패:** 내 파일의 오류 메시지와 `Role04/runtime/logs/`의 로그를 확인하세요. 정상 데이터는 준비·검증을 마친 뒤 교체하며, 교체 직전 데이터는 `Role04/runtime/backend/update_backups/`에 남습니다.
- **Windows 파일 갱신:** 심볼릭 링크 권한이 없으면 임시 폴더 복사 방식으로 처리합니다. 여유 디스크 공간이 필요합니다. Windows 실기기 실행은 미검증입니다.
- **Mac이 실행을 차단:** Finder에서 실행 파일을 우클릭 → 열기로 실행합니다.
- **서버 종료 후 다시 사용:** 실행 파일을 다시 더블클릭합니다.

실행 데이터는 `Role04/runtime/backend/`에 있습니다. 이 폴더를 지우면 등록한 파일과 갱신 데이터도 사라집니다. 다른 컴퓨터로 옮길 때는 저장소와 이 폴더를 함께 백업하세요.
