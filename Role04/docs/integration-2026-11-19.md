## 실행 조건과 남은 한계

- 이 컴퓨터에는 Ollama/Qwen 서버가 설치·실행되어 있지 않다. 실제 새 Qwen 설명 생성은 검증하지 못했다. 기존 팀 설명은 정상 반영된다.
- 팀 분류기 일부가 scikit-learn 1.5.1에서 저장되어 현재 1.9.1에서 버전 경고가 나온다. 실제 신규/수정 Python 파일의 프로젝트 예측과 확장자 역할 분류는 확인했다. 모든 유형의 분류 품질 검증을 대신하지 않는다.
- 팀 엔진은 등록된 프로젝트/역할 단어를 검색 필터로 해석한다. `데이터 ... 코드`처럼 여러 역할 단어를 넣으면 의도와 다른 역할이 선택될 수 있어 명확한 과목+역할 조건을 권장한다.
- Windows 실기기, 신규 OCR 전용 문서·이미지 검색 등록, OS 폴더 열기, 외부 사용자 평가는 미검증 또는 미지원이다.
- 폴더 감시는 GUI 서버 실행 중 동작한다. 강제 종료·정전 시 다중 파일 교체의 완전한 원자성은 보장하지 않으며 이전 데이터 백업이 남는다.
