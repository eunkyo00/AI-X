## GUI 연결 방안

1. Python 서버 시작 시 엔진을 한 번 초기화하고 재사용한다. 준비 상태를 `/health`로 제공한다.
2. `POST /search`에서 검색어를 전달하고 엔진의 순서를 그대로 유지한다.
3. `filename`을 GUI의 `name`으로 변환하고 file_id로 메타데이터의 역할·설명·크기·수정일을 결합한다. 날짜 형식은 표준화가 필요하다.
4. `chunk_text`는 검색에 대응된 본문 발췌로 표시한다. 자동 생성 추천 이유나 확인된 파일 관계로 표현하지 않는다.
5. `score`는 유사도 원점수이며 정확도 백분율로 표시하지 않는다. 기존 GUI 정규화는 점수를 보존하지 않아 점수 표시에는 보완이 필요하다.
6. 파일 경로는 서버에서 데이터셋 기준으로 해석한다. Windows 구분자와 한글 유니코드를 정규화하고 허용 폴더 내부 파일만 제공한다.
7. 현재 엔진에는 업로드·재인덱싱·관련 파일 관계·낮은 유사도 결과 제거가 없다. 내용이 있는 검색은 무관한 질문에도 최대 5건을 반환할 수 있으므로 빈 결과 정책은 별도 설계한다.
