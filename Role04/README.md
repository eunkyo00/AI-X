# GUI·사용성

파일 등록부터 상황 검색, 검색 근거와 관련 파일 확인, 파일 열기까지의 흐름을 데스크톱 화면으로 구현하는 역할입니다. 사용자가 처리 상태와 결과를 이해하고 필요한 파일에 쉽게 접근할 수 있도록 개선합니다.

## 주요 담당 업무

- 파일·폴더 등록, 검색 입력과 결과 목록 화면을 구현합니다.
- 추천 근거, 관련 파일과 확인된 참조·추정 관계를 표시합니다.
- 파일과 저장 위치 열기, 진행 상태와 오류 안내를 제공합니다.
- 대표 시나리오로 사용성을 점검하고 화면 흐름을 개선합니다.

## 주차별 계획

| 주차   | 주요 작업                                                    | 산출물·완료 기준                        |
| ------ | ------------------------------------------------------------ | --------------------------------------- |
| 4주차  | 파일 등록·검색·결과·관련 파일 화면을 설계합니다. PySide6 기본 화면을 준비하고 각 담당자와 표시할 데이터 형식을 합의합니다. | 화면 구성안과 기본 화면, 연동 항목 목록 |
| 5주차  | 파일·폴더 선택과 등록 상태 화면을 구현합니다. 검색어를 입력하고 기본 검색 결과 목록을 표시하도록 연결합니다. | 파일 등록·검색 입력·결과 목록 화면      |
| 6주차  | 맥락 검색의 추천 근거와 관련 파일 영역을 구현합니다. 확인된 참조와 추정 관계를 구분해 표시합니다. | 맥락 검색 결과·근거·관련 파일 표시      |
| 7주차  | 파일 및 저장 위치 열기를 연결합니다. 등록부터 검색·결과 확인·파일 열기까지 전체 흐름과 오류 안내를 점검합니다. | 전체 흐름이 동작하는 통합 GUI           |
| 8주차  | 대표 시나리오로 첫 완성본을 시연합니다. 사용자에게 필요한 정보가 화면에 표시되는지 확인하고 불편 사항을 기록합니다. | 시연 가능한 앱과 화면 개선 목록         |
| 9주차  | 발표 피드백을 정리하고 검색 동선, 결과 가독성과 오류 안내의 개선 순서를 정합니다. | 화면별 개선 우선순위                    |
| 10주차 | 관련 파일과 추천 근거의 표시를 보완합니다. 검색 조건을 수정하거나 잘못 연결된 결과를 구분하기 쉬운지 점검합니다. | 관련 파일 탐색과 결과 설명 개선         |
| 11주차 | 동일한 평가 질문에서 결과 순위와 근거를 확인하기 쉽도록 표시를 점검합니다. 화면 표시 오류와 실제 검색 오류를 구분합니다. | 비교 실험용 화면 점검 기록              |
| 12주차 | 대표 사용 흐름을 점검하고 조작 단계와 가독성을 개선합니다. 검색 중 상태, 빈 결과, 파일 열기 실패 등 예외 안내를 보완합니다. | 사용성 점검 기록과 개선된 화면          |
| 13주차 | 최종 버전의 화면 흐름과 기능 동작을 확인합니다. 검색 성능 평가를 방해하는 표시·연동 오류가 있는지 점검합니다. | 최종 GUI 점검 결과                      |
| 14주차 | 발표용 시연 순서를 정하고 반복 리허설을 진행합니다. 기능 변경을 최소화하고 재현되는 화면 오류를 수정합니다. | 시연 동선과 리허설 완료                 |
| 15주차 | 등록부터 파일 열기까지 개선된 앱을 시연합니다. 첫 완성본 이후 사용성이 어떻게 바뀌었는지 설명합니다. | 최종 앱 시연과 사용성 개선 발표         |

## 협업 기준

- **파일 처리·DB**에서 등록 상태와 파일 정보를 받고, **AI·검색**에 질의를 전달해 순위·근거·관련 파일을 표시합니다.
- **데이터·평가**와 대표 질문 및 시나리오를 선정하고 사용성 점검 결과를 공유합니다.
- 검색 점수나 정답을 화면에서 임의로 바꾸지 않으며, 검색 근거에 맞춰 확인된 사실과 추정을 구분합니다.
