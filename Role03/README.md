# 파일 처리·DB

등록된 파일에서 내용·시간·참조 정보를 추출하고 파일 ID와 메타데이터를 저장하는 역할입니다. 검색과 GUI가 동일한 파일을 식별하고 변경 사항을 반영할 수 있도록 데이터 기반을 관리합니다.

## 주요 담당 업무

- 지원 파일 형식에서 텍스트, CSV 구조와 코드의 읽기·쓰기 참조를 추출합니다.
- 파일 ID, 원본 경로, 생성·수정 시각과 처리 상태를 저장합니다.
- 파일의 명시적 참조와 그 근거를 데이터베이스에 관리합니다.
- 추가·변경·삭제 정보를 제공해 검색 인덱스 갱신을 지원합니다.

| 14주차 | 시연용 파일의 등록과 갱신을 반복 점검합니다. 재실행 시 동일하게 준비할 수 있도록 데이터 준비 절차를 정리합니다. | 시연 데이터와 준비 절차                      |

## 협업 기준

- **AI·검색**에 파일 ID, 내용·시간·참조 근거와 변경 정보를 제공합니다. 임베딩과 검색 순위 계산은 AI·검색이 담당합니다.
- **데이터·평가**와 추출 내용을 검수하고, **GUI·사용성**에 등록 진행 상태와 오류 내용을 제공합니다.
- 사용자가 지정한 파일만 처리하고 원본을 자동 수정하거나 실행하지 않습니다. 코드의 저장 구문은 참조 근거이며 실행 사실을 의미하지 않습니다.
