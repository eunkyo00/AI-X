# 6주차 작업 보고서

이번 주: 10월 12~18일 · 담당: Role03 파일 처리·DB

## 이번 주 완료한 작업

- **기존 파일 자료 확인:** 1번 담당자의 CSV에 있는 161개 파일 정보와 실제 파일 위치를 확인했다. 검색 결과가 올바른 파일을 가리키도록 하기 위한 작업이다.
- **파일 정보 DB 저장:** 파일 정보와 추출된 본문을 한곳에 저장하고 파일 ID로 꺼낼 수 있게 만들었다. 검색과 화면에서 같은 파일 정보를 사용하기 위해 필요하다.
- **파일 사이의 연결 확인:** 코드에서 어떤 파일을 읽거나 저장하는지 찾아 근거를 기록했고, 실제 등록 파일과 경로가 맞는 연결 4건을 찾았다. 검색할 때 함께 사용된 관련 파일을 추천하는 데 필요한 정보다.
- **사용 예제와 동작 확인:** 1번 담당자가 파일 정보와 연결 정보를 가져오는 예제를 만들고, 테스트 5개를 통과했다. 검색 기능에 연결하기 전에 기본 동작을 확인하기 위한 작업이다.

1번 담당자의 코드와 자료는 수정하지 않았다. 검색 기능 연결은 다음 주에 진행한다.

## 다음 주 할 일 — 7주차, 10월 19~25일

- **1번 담당자의 검색과 연결:** DB의 파일 정보와 연결 근거를 검색 기능에서 사용할 수 있도록 함께 연결하고 확인한다.
- **4번 담당자의 화면과 연결:** 파일 등록 요청을 받고, 처리 중·완료·실패 상태를 화면에 보여줄 수 있도록 연결한다.
- **파일 등록 오류 점검:** 중복 등록, 잘못된 경로, 본문 추출 실패를 확인하고 처리한다. 이번에 발견한 파일 크기 불일치 36개와 텍스트 없음·미지원 12개도 원인을 확인해 처리 방향을 정한다.
- **전체 흐름 확인:** 파일 등록 → DB 저장 → 검색 → 파일 열기까지 담당자들과 함께 점검한다.

## DB 사용 방법

- **저장 위치:** `Role03/output/files.sqlite3` — 파일 정보와 파일 간 연결 근거가 들어 있다.
- **DB 만들기·갱신:** 저장소 최상위에서 `python3 Role03/file_db.py` 실행.
- **사용 예제:** `python3 Role03/query_example.py` 실행.
- **1번 담당자 연동:** `Role03.file_db`의 `get_file(DB경로, 파일ID)`로 파일 정보를, `get_relations(DB경로, 파일ID)`로 연결 근거를 조회한다. 연결 상태가 `resolved`인 항목부터 활용한다.

연결 근거는 코드에 적힌 파일 참조이며 실제 실행 기록은 아니다. 파일명만 같거나 대상 경로가 불분명한 참조는 확정 연결하지 않았다.
