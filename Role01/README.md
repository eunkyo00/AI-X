# AI·검색

자연어 질의를 분석하고 내용·시간·역할·파일 관계를 결합해 검색 순위와 추천 근거를 만드는 역할입니다.

## 주차별 역할

| 주차   | 할 일                                                        |
| ------ | ------------------------------------------------------------ |
| 4주차  | 검색 입력·출력 형식과 임베딩 방식을 정하고 샘플 데이터로 동작을 확인합니다. |
| 5주차  | 파일명·키워드 검색과 임베딩 기반 의미 검색을 구현합니다.     |
| 6주차  | 시간·역할·관계 점수를 결합해 맥락 검색을 구현합니다.         |
| 7주차  | GUI와 검색 기능을 연결하고 결과·근거 반환 오류를 수정합니다. |
| 8주차  | 첫 완성본의 검색 흐름을 시연하고 Baseline 결과와 비교합니다. |
| 9주차  | 중간발표 피드백을 반영해 검색 개선 항목을 정합니다.          |
| 10주차 | 잘못된 작업 연결과 관련 파일 누락을 줄이도록 맥락 추론을 개선합니다. |
| 11주차 | 시간·역할·관계 단서를 하나씩 제외하며 효과를 비교합니다.     |
| 12주차 | 검색 속도와 결과 설명을 개선하고 예외 상황을 처리합니다.     |
| 13주차 | 검색 방식을 고정하고 최종 평가 실행을 지원합니다.            |
| 14주차 | 기능 변경을 최소화하고 시연 중 발생하는 검색 오류를 수정합니다. |
| 15주차 | 개선된 검색 결과와 8주차 대비 차이를 발표합니다.             |
