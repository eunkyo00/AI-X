# AI·검색

사용자의 상황 설명을 검색 조건으로 해석하고, 파일 내용·시간·역할·관계를 종합해 목표 파일과 관련 파일을 찾는 역할입니다. 검색 순위뿐 아니라 해당 파일을 추천한 이유도 함께 제공합니다.

## 주요 담당 업무

- 질의에서 작업 내용, 시간 범위와 찾는 파일의 역할을 분석합니다.
- 파일과 질의를 임베딩으로 변환하고 의미적으로 가까운 파일을 검색합니다.
- 의미·시간·역할·관계 점수를 결합해 검색 결과를 재정렬합니다.
- 관련 파일과 추천 근거를 GUI에서 표시할 수 있는 형태로 반환합니다.

## 주차별 계획

| 주차   | 주요 작업                                                    | 산출물·완료 기준                                 |
| ------ | ------------------------------------------------------------ | ------------------------------------------------ |
| 4주차  | 샘플 파일의 추출 내용을 확인하고 임베딩 모델과 검색 방식을 검토합니다. 파일 ID를 기준으로 검색 입력·출력 형식을 팀과 합의합니다. | 모델 후보와 검색 인터페이스 초안, 샘플 동작 확인 |
| 5주차  | 파일명·본문 키워드 검색과 임베딩 기반 의미 검색을 구현합니다. 평가 담당자가 같은 질문으로 비교할 수 있도록 순위와 실행 시간을 반환합니다. | 두 Baseline 검색 실행, 평가 가능한 결과 목록     |
| 6주차  | 질의의 시간·역할을 해석하고 의미 점수에 메타데이터와 관계 점수를 결합합니다. 직접 연결된 파일을 우선 활용해 관련 파일을 반환합니다. | 맥락 검색 1차 버전, 목표·관련 파일과 근거 반환   |
| 7주차  | GUI에서 검색을 호출하도록 연결합니다. 빈 결과, 정보 누락, 잘못된 질의 처리와 파일 ID 연결 오류를 수정합니다. | 검색 입력부터 결과·근거 표시까지 통합 동작       |
| 8주차  | 첫 완성본의 검색 설정을 기록하고 대표 시나리오를 시연합니다. 평가 담당자와 Baseline 대비 결과를 확인합니다. | 시연 가능한 검색 기능, 설정 기록과 비교 결과     |
| 9주차  | 발표 피드백과 실패 사례를 검토합니다. 질의 해석, 순위, 관계 확장 중 개선할 항목의 우선순위를 정합니다. | 검색 개선 목록과 우선순위                        |
| 10주차 | 다른 작업의 파일이 잘못 연결되거나 관련 파일이 누락되는 원인을 수정합니다. 개발·검증 데이터에서 가중치와 관계 임계값을 조정합니다. | 개선된 맥락 검색, 변경 사항 기록                 |
| 11주차 | 시간·역할·관계를 하나씩 제외한 검색을 실행합니다. 후보 재정렬 효과와 관계를 통한 후보 확장 효과를 구분해 비교합니다. | 단서별 비교 실험 결과와 재현 가능한 설정         |
| 12주차 | 검색 지연을 줄이고 추천 근거를 이해하기 쉽게 정리합니다. 모호한 질의와 메타데이터 누락 상황을 점검합니다. | 속도·설명·예외 처리 개선                         |
| 13주차 | 모델과 가중치 등을 고정한 후 최종 평가 실행을 지원합니다. 최종 평가 결과를 보고 다시 설정을 조정하지 않습니다. | 고정된 검색 버전과 최종 실행 결과                |
| 14주차 | 기능 변경을 최소화하고 시연 질문을 반복 실행합니다. 재현되는 검색 오류를 수정하고 발표용 검색 예시를 정리합니다. | 시연 점검 결과와 검색 방식 설명 자료             |
| 15주차 | 첫 완성본 대비 검색 방식과 결과가 어떻게 달라졌는지 설명합니다. 효과가 있었던 단서와 남아 있는 한계를 발표합니다. | 최종 검색 데모와 개선 내용 발표                  |

## 협업 기준

- **파일 처리·DB**에서 추출 텍스트, 시간 정보, 파일 ID와 참조 근거를 받습니다. 임베딩과 벡터 검색은 AI·검색이 담당합니다.
- **데이터·평가**에서 개발·검증 질문과 실패 분석을 받으며, 검색 결과와 설정을 전달합니다.
- **GUI·사용성**에는 순위, 관련 파일과 추천 근거를 전달합니다. 확인된 참조와 추정 관계를 구분합니다.
