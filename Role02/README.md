# 데이터·평가

검색 성능을 검증할 수 있는 작업별 파일 데이터셋과 정답을 만들고, 검색 방법별 결과를 비교하는 역할입니다. 원하는 파일을 잘 찾는지와 관련 없는 파일을 잘 제외하는지를 확인하고 실패 원인을 정리합니다.

## 주요 담당 업무

- 작업별 파일 세트를 구성하고 파일 역할·참조 관계·내용의 일관성을 검수합니다.
- 상황 기반 평가 질문, 목표 파일과 관련 파일 집합을 정답으로 관리합니다.
- 작업 단위로 개발·검증·최종 평가 그룹을 나누고 데이터 누출을 방지합니다.
- Baseline과 맥락 검색을 같은 조건으로 비교하고 성능·실패 사례를 보고합니다.

## 협업·평가 기준

- **파일 처리·DB**의 추출 결과를 원본과 비교하고, **AI·검색**이 반환한 결과를 정답과 대조합니다. **GUI·사용성**과 대표 시나리오를 공유합니다.
- 목표 파일은 MRR·Hit@K, 관련 파일은 Precision@K·Recall@K로 평가합니다. K는 1·3·5이며 관련 파일 평가에서 출발 파일은 제외합니다.
- 같은 작업의 질문·중복 파일과 공유 파일로 연결된 작업은 같은 분할에 둡니다. 검색 대상은 공통 전체 파일 집합을 사용하되 최종 평가 질문·정답은 설정 조정에 사용하지 않습니다.
- 정답 작업 ID는 검색 특징에 넣지 않습니다. 합성 시간은 실제 관측 시간과 구분하고, 생성·수정 시각을 실제 사용 시각으로 단정하지 않습니다.
