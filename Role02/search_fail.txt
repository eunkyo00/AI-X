## 1. 평가 결과 요약

- 전체 평가 쿼리 수: 158개
- 검색 성공: 129개

※ Hit@5는 정답 파일이 검색 결과 상위 5개 안에 포함되었는지를 평가하는 지표이다. 단, 파일명이 중복되는 경우 동일한 파일이 아닌 다른 파일을 정답으로 잘못 인식할 가능성이 있어 추가 검증이 필요하다.

## 3. 성공으로 표시됐지만 추가 확인이 필요한 문제

아래 항목은 평가에서 성공으로 처리됐더라도 검색 결과의 정확성을 추가로 확인할 필요가 있는 사례이다.

1. 서로 다른 파일이 같은 파일명으로 표시되는 문제
   - README.md, notebook.ipynb, assignment.md 등의 파일명이 여러 번 검색 결과에 등장한다.
   - 파일명만 비교하면 실제 정답 파일이 아닌 동명의 파일도 정답으로 판정될 수 있다.

2. 관련성이 낮은 파일이 상위 검색 결과에 포함되는 문제
   - 예: 꿀 생산량과 가격 관계를 시각화하는 강의자료 검색에서 README.md가 여러 개 상위에 등장한다.
   - 예: 조류 수량을 여러 그래프로 비교하는 강의자료 검색에서 README.md가 반복적으로 등장한다.

3. 노트북 검색 결과의 중복 문제
   - 예: 조류 날개폭과 수량을 그린 실습 풀이 검색에서 notebook.ipynb가 여러 개 등장한다.
   - 예: 버섯 비율 시각화의 비어 있는 시작 노트북 검색에서 notebook.ipynb가 여러 개 등장한다.

4. 과제 안내 검색 결과의 중복 문제
   - 예: 입력 폼 데이터를 정리하는 과제 안내 검색에서 assignment.md가 여러 개 등장한다.

※ 위 사례들은 파일명 중복과 검색 순위 문제를 확인하기 위한 후보이며, 모든 항목이 실제 오답이라고 확정된 것은 아니다.

## 4. 개선이 필요한 부분

1. 파일명 대신 file_id 또는 전체 경로를 기준으로 정답 여부를 비교한다.
2. 검색 실패 쿼리의 정답 파일이 실제로 텍스트 추출 및 임베딩 대상에 포함되어 있는지 확인한다.
3. 비슷한 내용을 가진 파일들이 상위 검색 결과를 차지하는 원인을 분석한다.
4. 시계열 코드처럼 파일명이 유사한 자료는 주차, 분석 기법, 데이터셋 등의 메타데이터를 활용한다.
5. 검색 결과에서 중복 파일명이나 동일 파일의 중복 청크가 과도하게 노출되는지 확인한다.
6. 위 문제를 개선한 뒤 동일한 평가 쿼리로 Hit@5를 다시 측정한다.
7. 파인튜닝을 진행하기 전에 파일 식별과 텍스트 추출, 검색 순위 개선을 우선 검토한다.
