# 데이터셋

로컬 파일 검색 기능을 개발하고 평가하기 위한 데이터셋입니다.

## 폴더 구성

- `raw/`: 검색 대상이 되는 원본 문서, 데이터, 코드와 결과물
- `labeled/`: 원본 파일의 역할·관계와 평가 질문·정답을 정리한 라벨 데이터

## 데이터 구성

- 작업별로 설명 문서, 입력 데이터, 코드와 결과물을 포함합니다.
- 비슷한 이름의 파일, 수정본과 무관한 파일을 함께 구성합니다.
- 파일명과 폴더명이 모호해도 내용과 관계로 검색할 수 있도록 구성합니다.

## 라벨 정보

- 파일 ID와 원본 경로
- 소속 작업과 파일 역할
- 관련 파일과 관계 근거
- 평가 질문과 정답 파일

## 관리 기준

- 검색 인덱스에는 `raw/`의 파일만 포함합니다.
- `labeled/`는 검색 결과를 검증하는 정답으로 사용합니다.
- 원본 파일과 라벨은 파일 ID로 연결합니다.
- 개인정보나 공개 허가가 없는 파일은 업로드하지 않습니다.
- 합성 데이터와 임의로 설정한 시간 정보는 별도로 표시합니다.
